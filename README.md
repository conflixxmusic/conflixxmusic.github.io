# ConFlixx - Official Music (landing page)

Static one-page site: dark magenta/black design, hero banner, three album
cards with Apple Music + Spotify links, and follow buttons.

## Files
- `index.html` - the whole page (HTML + CSS, no build step, no dependencies)
- `` - hero banner and the three album covers (supplied art, unchanged)

## Run
Open `index.html` in a browser, or serve the folder with any static host.
